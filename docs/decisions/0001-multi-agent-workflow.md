# 0001 — Fluxo de desenvolvimento multi-agente

- Status: aceita
- Data: 2026-11-23

## Contexto

O projeto precisava separar responsabilidades no desenvolvimento e garantir QA e commit a cada etapa.

## Decisão

Adoção do fluxo multi-agente descrito na seção 5 do `rules.md` (na época): agentes especializados coordenados por um orquestrador, com QA e commit a cada etapa.

## Alternativas consideradas

Não registradas na época.

## Consequências

- Responsabilidades separadas entre os agentes.
- QA e commit garantidos a cada etapa.
